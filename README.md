# ATLAS 34.0 — MOTION GLASS

ATLAS 34 keeps the Live Brain and analytics engine from 33 while making the interface cleaner, faster to scan, easier to access, and more animated.

## Interface pass
- Cleaner glass navigation and stronger active-page state
- One-click global Search control in the header plus existing `/` shortcut
- Better keyboard focus visibility and mobile/tablet navigation
- Darker, calmer surfaces with cyan/violet/mint signal colors
- Animated page reveals, status beacon, hero scan line, flowing analytics headings, hover elevation and logo motion
- More consistent cards, graph panels, inputs, empty states, spacing and responsive layouts
- Reduced-motion support for accessibility

## Core systems retained
- Automatic final-game archive and recovery
- Historical database / archive vault
- Team trend engine and factual ATLAS Insights
- Game Replay
- Graph Studio and saved graph views
- Global search
- My ATLAS pins
- Data Fabric diagnostics
- 32-team normalization

Render start command remains `python server.py`.
