# ATLAS 33.0 — LIVE BRAIN

ATLAS 33 turns the final-game archive into an automatic analytics layer.

- Automatic final capture and throttled missed-game backfill
- Archive coverage validation and quality reporting
- Live Brain club trends and deterministic evidence-backed insights
- Game Replay with stored score snapshots and captured play tape
- Graph Studio with archive-backed metrics and locally saved views
- Global search for teams, players, and archived games
- Home control center with recent automatic captures
- Data Fabric archive-autopilot diagnostics
- 32-team abbreviation normalization retained

No projected or fabricated performance values are used to fill missing data.

Render start command: `python server.py`
