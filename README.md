# HuddleIntel V8 — Interactive
All UI elements that visually behave like links/cards now have a destination:
- 5 top navigation buttons switch full pages.
- Player cards open detailed player profiles with roster metadata + available live box-score categories.
- Standings rows open team season profiles.
- Schedule rows open game-detail panels.
- News cards open story-detail panels.
- Modal panels close via Close or backdrop click.
- Existing V7 live data endpoints and refresh intervals remain intact.
